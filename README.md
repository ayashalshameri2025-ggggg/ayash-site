# موقع عياش محمود الشميري

## محتويات المجلد
* `index.html`: الصفحة الرئيسية وكل الأقسام.
* `style.css`: التنسيق بألوان الهوية (#0B1020 / #2563EB / #7C3AED).
* `script.js`: التبويبات والمحادثات.
* `netlify/functions/chat.js`: دالة تربط المساعد الذكي دون كشف المفتاح.

## الرفع على GitHub
1. أنشئ مستودعاً باسم `ayash-site`.
2. ارفع جميع الملفات والمجلدات كما هي، بما فيها `netlify/functions`.

## الربط بـ Netlify
1. من Netlify اختر **Add new site ← Import an existing project** واختر المستودع.
2. اترك إعدادات البناء فارغة، لأن الموقع ملفات ثابتة، ثم اضغط Deploy.
3. من **Site settings ← Environment variables** أضف:
   * `AI_API_KEY`: مفتاح خدمة الذكاء الاصطناعي.
   * `AI_MODEL` (اختياري): اسم النموذج.
   * `AI_API_URL` (اختياري): رابط الخدمة إن لم تكن Groq.
4. أعد النشر بعد إضافة المتغيرات.

## قبل النشر للعموم
* املأ رابط نموذج التسجيل في الحساب الذهني داخل `script.js`.
* تأكد من صحة أرقام التواصل وأسماء الدورات.
* لا تضع أي مفتاح API داخل الملفات.
